Changelog

Nik follows Semantic Versioning. This page summarises each release; the complete, line-by-line history is CHANGELOG.md in the repository, and every version is published under Releases.

2.28.0 2026-11-11

  • added Admins change an account's name, role and password, or disable it; everyone changes their own password under My account.
  • changed The audit log is written by the server for every caller and can no longer be written from the browser.
  • changed Report header, mail and threat-intelligence settings are for admins only.
  • fixed Accounts are locked after repeated wrong passwords; sessions end with a password change.

2.27.0 2026-11-11

  • added Saves are queued, retried and never dropped; a bar says when changes are not saved yet.
  • added Changes made by two analysts to the same incident are merged instead of overwritten.
  • added A session that expires asks for the password again and keeps the unsaved work; removing a flag has an Undo.
  • fixed Lost updates between concurrent writers of an incident, on the server and in the app.

2.26.0 2026-11-11

  • added Keyboard shortcuts: F flags and C comments on the row under the pointer, ? lists them.

2.25.0 2026-11-11

  • added Incident status (open, in progress, closed) and assignee: set from the Summary or the panel's right-click menu, shown and filtered in the incidents panel, stated in the report.

2.24.0 2026-11-11

  • changed The incident report lists only what was flagged (events, indicators, samples, e-mails, captures, addresses and their evidence files); "Include everything" gives the full inventory.

2.23.0 2026-11-11

  • added Right-click on every row and item, with one menu built the same way everywhere; samples, e-mails, captures, addresses and indicators can be flagged from it.
  • fixed The menu no longer closes by itself when the list under it reloads.

2.22.1 2026-11-11

  • changed The tab bar shortens its labels instead of scrolling; buttons and header controls share fixed heights; list panels remember being closed; a real favicon.

2.22.0 2026-11-11

  • added Paste or drag text onto the app: an address is offered for a scan, a hash, an IP address or a domain for a search and a lookup; defanged text is understood.

2.21.0 2026-11-11

  • added URL Analysis: the isolated browser visits a link and Nik returns a screenshot, the redirects, the page's forms and a phishing verdict with its reasons; on its own or in an incident, with indicators, timeline and report.

2.20.0 2026-11-11

  • added Analyse without an incident: New analysis, Start analysis on a dropped file, and the artifact page with links to incidents, tags and related artifacts. A file already analysed is recognised before the upload.
  • added A rail of icons with a collapsible side panel for incidents and artifacts; audit log, users, backup and settings moved to the rail.

2.19.0 2026-11-11

  • added Artifacts in the API: a file, an e-mail or a packet capture analysed without an incident, listed for the team, linked to incidents later, tagged and related to its source.
  • changed Removing a sample, an e-mail or a capture from an incident keeps it as an artifact; deleting an incident deletes what only that incident references.

2.18.3 2026-11-11

  • changed Backend dependencies: newer minimum versions of FastAPI, dnspython, publicsuffixlist, Pillow and cryptography.

2.18.2 2026-11-11

  • changed New documentation: a user guide with screenshots, Deployment, Architecture and Developer guide pages, a shorter homepage and README.

2.18.1 2026-11-11

  • security Every path to the sample store, in the API and in the analyzer and capa workers, is checked to stay inside the store; parser errors on malformed executables stay in the server log; workflows run with a read-only token.

2.18.0 2026-11-10

  • changed Analysis tabs in three groups: overview (Summary, Timeline, IOCs), threats (Mail, Malware, Network) and host (Endpoint Artifacts, Event Logs, Browser Forensics, Command History).
  • removed Load demo data and the tail -f side panel; the Timeline tab shows the same events.

2.17.1 2026-11-10

  • changed Repository layout: the app in frontend/, the analysis workers in workers/, the backend split into core, workers and malware packages. npm scripts now run from frontend/; Compose deployments need no change.
  • removed Python bytecode committed by mistake.

2.17.0 2026-11-10

  • added Network Analysis: pcap and pcapng read by Wireshark's engine (packet list with Wireshark's colours, protocol tree, bytes, display filters, Follow Stream, Export Objects, TLS decryption with a key log), with a summary of hosts, DNS, HTTP, TLS server names, submissions and beacons.
  • added Isolated browser: a DevTools-like Network panel with every request, bodies in clear; submissions held until sent; sessions kept in the incident, as HAR and as a pcapng rebuilt with HTTPS in clear.
  • changed The Network Logs placeholder became Network Analysis; CI tests PostgreSQL 18 only.
  • fixed A moderate advisory in a build-tool dependency (minimatch).

2.16.0 2026-11-10

  • added Previews of mail attachments: PDF, Office, OpenDocument, RTF and images as page images, rendered in a new isolated worker (LibreOffice with macros disabled, pdfium).
  • added Isolated browser: HTML attachments and links run in Chromium in its own container; you click, type and scroll on screenshots. No network unless allowed for one session, never private addresses; every session audited.

2.15.0 2026-11-10

  • added Threat intelligence: reputation of indicators from VirusTotal, AbuseIPDB, abuse.ch, AlienVault OTX, urlscan.io, GreyNoise, Shodan InternetDB and Google Safe Browsing, in the IOCs tab and in Where seen, with Check now.
  • added Automatic lookups per type (IP, URL and domain, hash) within each free tier; never for private addresses, internal names, allowlisted values or TLP:RED incidents. API keys stored encrypted.

2.14.0 2026-11-10

  • added Mail Analysis tab: phishing triage of .eml and Outlook .msg files with route, SPF/DKIM/DMARC, sender checks, links, a sandboxed body view, attachment analysis, a hex view and a scored verdict.
  • added Settings → Mail analysis (your domains and mail servers); e-mails in the IOC index, the timeline, the report and the sidebar.
  • changed Malware Analysis recognises PNG, JPEG and GIF images; a sample sent from an e-mail records where it came from.

2.13.0 2026-11-10

  • added Ticket ID, short title and severity tag for incidents; the name becomes [INC-2041] Invoice phishing, finance.
  • added Right-click menu on indicators, event rows and incidents, with a one-click allowlist (domain or /24, with Undo) and defanged copy.
  • added Drop a file anywhere: Nik recognises it and imports it into the right tab of the open incident or a new one.

2.12.3 2026-11-10

  • fixed deploy/upgrade-postgres.sh could stop with "the new db container is not PostgreSQL 18" while PostgreSQL 18 created its database; a run that stopped there is resumed by running the script again.

2.12.2 2026-11-10

  • manual step PostgreSQL 18 on a new volume. After git pull, before compose up, run sudo deploy/upgrade-postgres.sh: backup, dump and restore, row-count check, restart. The PostgreSQL 16 volume stays for a rollback for 14 days.
  • changed CI runs the backend tests on PostgreSQL 16 and 18 too.

2.12.1 2026-11-10

  • changed Frontend toolchain on Vite 8 (a much faster build and a smaller main bundle), ESLint 10 and lucide-react 1.x. No visible change except Chrome's sub-tab icon. Local development needs Node.js 22 (or 20.19+).
  • changed Dependabot proposes minor and patch releases only; major releases are planned as their own changes.
  • fixed Keys typed right after Ctrl/Cmd+K reach the search palette.

2.12.0 2026-11-10

  • added Event Logs tab (Windows): raw .evtx files parsed on the server (records left after a clear recovered) or a native Get-WinEvent export; about 50 curated event IDs, a coverage chart with silences and clears, logon sessions and a built-in ruleset (log cleared, brute force, RDP outside hours, suspicious PowerShell, services from user paths, new admins).
  • added IOC correlation: indicators from every tab indexed on the server, an IOCs tab with the number of other incidents each one appears in, Where seen across every analyst's incidents, a shared allowlist, export as CSV, STIX 2.1 or MISP.
  • added Global search: Ctrl/Cmd+K or / opens a nik> prompt over incidents, indicators, samples and the open incident's events and notes; > lists actions.
  • added Incident report as PDF or HTML, also via the API: executive summary, flagged events, ATT&CK techniques, indicators, samples, event-log coverage, notes and an evidence appendix with SHA-256; TLP, English or Italian, organisation name and logo.
  • added Start on boot and nightly backups with systemd (deploy/install-systemd.sh); dependency audits in CI and grouped monthly Dependabot updates.
  • changed The backend image includes Pango for the PDF report (about 80 MB larger). pyzipper 0.4.0 fixes PYSEC-2026-3044 in the protected sample zips.

2.11.2 2026-11-10

  • fixed Samples stored by releases before 2.7.0 are made readable by the analysis workers at startup and on re-upload (the Code and Capabilities views failed on them); the workers report an unreadable sample plainly.

2.11.1 2026-11-10

  • fixed podman compose up --build on RHEL: every image is named with its registry (docker.io/…) instead of being resolved through registry.redhat.io; the capa worker no longer uses tmpfs uid / gid options, which Podman rejects.

2.11.0 2026-11-10

  • added Admins add their own capa rules in Settings; the capa worker checks each one, and their matches are marked custom.
  • changed The Code view lists every function of large binaries (the 3,000 limit is gone), and opening a function stays fast.
  • changed Decompiling a function on demand takes seconds instead of a new analysis; the up-front pass decompiles the code worth reading first.
  • changed Passwords are hashed with bcrypt directly (passlib removed); existing passwords keep working.

2.10.0 2026-11-10

  • added Capabilities view: what a sample's code can do according to Mandiant capa, mapped to MITRE ATT&CK and the Malware Behavior Catalog, with links to the functions where each capability was found.
  • added capa runs in its own isolated worker after upload and Re-analyse, one sample at a time.
  • added The Code view shows each function's capabilities, and Start here ranks unrecognised functions with capabilities higher.

2.9.0 2026-11-10

  • added Code view triage: library code recognised by FLIRT signatures or by the Rust crate its panic paths name is hidden by default, with the crates listed and each function's origin shown.
  • added Start here: the unrecognised functions worth reading first (suspicious APIs, indicators used, complexity).
  • added The strings each function uses, and a Used by column in the IOC table that opens the function.
  • added Rename and comment functions, per sample, in the list, graphs and pseudo-C.
  • added Admins upload FLIRT signatures in Settings.

2.8.1 2026-11-09

  • fixed Switching functions in the Code view with a graph open could blank the whole application.
  • added A rendering error in one view now stays in that view, with a button to reload it; the rest of Nik keeps working.

2.8.0 2026-11-09

  • added Decompiled panel in the Code view: the pseudo-C of each function from Ghidra's decompiler (rz-ghidra, already in the analyzer image), with highlighting, links from calls to the called functions and suspicious APIs in red. Functions are decompiled up front within a time budget and the rest on first open.
  • fixed The analyzer worker survives rizin crashes on large binaries instead of losing the whole analysis.

2.7.0 2026-11-09

  • added Code view: functions, call graph and control-flow graphs of a sample, disassembled by an isolated rizin worker and laid out with ELK (orthogonal edges, loops on the side, full disassembly per block, pan, zoom and minimap). Functions that reach suspicious APIs are highlighted and can be flagged.
  • added Analyzer worker service in the Compose stack: read-only sample store, non-root, read-only filesystem, no capabilities, memory / CPU / time limits, no internet access.

2.6.0 2026-11-09

  • added Structure view for samples: PE headers, sections with entropy, imports, exports, resources and imphash (via pefile); ELF and Mach-O with Nik's own parsers.
  • added YARA scanning with a built-in rule set and admin-managed rules (Settings → YARA rules, validated before saving); matches raise the sample severity. Re-analyse runs the current engine again on a stored sample.

2.5.0 2026-11-09

  • added Malware Analysis tab: samples stored on the server (by SHA-256, never executed) and analysed statically: hashes, file type, entropy chart, strings and indicators of compromise, flaggable and visible in the timeline. Downloads as an AES zip with the infected password or a custom one. New REST endpoints under /api/samples.
  • added Built-in malware ruleset for the SOC engine (injection, anti-analysis, persistence, C2 patterns, encoded PowerShell, throwaway TLDs, ransomware, credentials).

2.4.0 2026-11-09

  • added End-to-end smoke test (Playwright) of the whole stack, run in CI: first-run setup, sign-in, new incident, demo data, timeline and tail panel.
  • added This documentation site, served from /docs on GitHub Pages.
  • added Prettier for the frontend and ruff format for the backend, checked in CI; the code base was reformatted once, with no behaviour change.
  • changed Large browser histories (hundreds of thousands of visits) stay responsive: each URL is parsed once per event, text columns sort with a shared collator, the table search never blocks typing, and a flag no longer rebuilds the Timeline or the tail panel.
  • security Frontend build dependencies flagged by npm audit updated (Vite 6.4.6, PostCSS, nanoid, browserslist, source-map-js); development-time tools only.

2.3.1 2026-11-09

  • added ESLint (React and hooks rules) for the frontend and Ruff for the backend; CI runs both.
  • fixed The Events, Commands, Artifacts and Timeline tabs no longer recompute their memoized rows on every render when an incident has no flags; backend errors keep their original cause; unused code removed.

2.3.0 2026-11-06

  • added tail -f side panel: the latest 60 timestamped events of the open incident, newest at the bottom, toggled from the tab bar and remembered per tab.
  • changed Terminal look, step 2: every page (Summary, Browser Forensics, Command History, Endpoint Artifacts, Timeline, Network Logs, Settings, Backup) uses the design tokens. Analyst flags use the green accent, SOC rows their severity colour.
  • changed The dark: Tailwind variant is gone: Nik is dark only.

2.2.0 2026-11-06

  • added Terminal look, step 1: named colour tokens, bundled Inter and JetBrains Mono fonts (no CDN), sign-in and first-run screens with the NIK banner and a live $ nik status box.
  • changed UI kit, sidebar, header, tab bar and OS picker with square corners, monospace labels and the green accent; the header shows host / user with the OS.
  • changed The light theme and its toggle were removed.

2.1.0 2026-11-06

  • added ASCII skull loaders, generated at any size, with eyes that look around and blink; opening an incident shows the real download progress and a Cancel button.
  • changed Loading, error and empty states use the skull; busy buttons use the inline micro skull. Skulls stay still when the OS asks to reduce motion. The spinner is gone.

2.0.0 2026-11-04

  • added Several profiles per browser ("Default", "Profile 1", "Work"…), each with its own files and data; the timeline and flags name the profile; profile parameter on the upload endpoint and the Cortex XSOAR command; Alembic migration 0003_browser_profiles.
  • breaking Browser data moved to data.browser.browsers[id].profiles[profileId]; the upload response target is now browser/<id>/<profile>/<source>. The server converts pre-2.0.0 data on create, patch, fetch and restore, so old exports and backups still import.

1.2.0 2026-11-04

  • added Safari in Browser Forensics (macOS): History.db, Downloads.plist and Bookmarks.plist (Reading List included), with a dependency-free property list parser for binary and XML plists; Safari uploads through the REST API.

1.1.0 2026-11-04

  • added 304 Not Modified on If-None-Match, JSON Merge Patch (RFC 7396) on PATCH, os in the summary listing, frontend unit tests in CI.
  • changed Lazy loading: sign-in downloads only the light incident list; an incident's artifacts are fetched when it is opened, behind a non-blocking loading state; edits send only what changed.

1.0.0 2026-07-11

  • added First release: browser, command history and endpoint artifact analysis, super-timeline, SOC detection rules, case management, full backup, authentication, audit log and the external REST API.
